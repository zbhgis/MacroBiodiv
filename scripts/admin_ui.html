说明

· 粘贴的 DOI 会立即抓取元数据，并调用本地大模型做中文翻译（初译 + 审校，两重处理）；只有点「发布」后才写入 meta/papers.json、生成站点并提交。
· 封面图：图片可直接粘贴 / 拖进 DOI 输入框（进「待配区」，抓取后按顺序自动配给新文献）， 或在每篇卡片的封面区块单独上传；服务端校验真实格式（PNG/JPEG/WebP/GIF，≤8MB）后存 assets_src/covers/{id}.{ext}，发布时按 id 探测写入 papers.json，前台展示在卡片顶图与详情页。
· 大模型配置走环境变量 LLM_API_KEY / LLM_BASE_URL / LLM_MODEL_NAME（OpenAI 兼容接口）。 限流预案：429 指数退避并遵守 Retry-After → 重试耗尽进入 60s 断路冷却（期间直接跳过不撞 API）→ 审校失败或超预算自动降级为「仅初译」→ 初译失败则中文留空。任何失败都不阻断抓取与发布， 事后用文献管理的「翻译缺中文的」批量回补（只补空缺、可反复执行）。
· 译文（中文标题 / 中文摘要）在表单里可直接修改，修改稿视为定稿 —— 重新抓取不会覆盖，只有「重新翻译」会重写。
· 文献 id 由 DOI（小写）sha1 前 10 位算出 —— 重复 DOI 发布时会被自动跳过；封面文件名与 id 一一对应，换封面即覆盖。
· 「重新抓取」更新标题 / 作者 / 期刊 / 摘要等自动字段；被引数（cited_by）仅随抓取入库存档，界面与站点均不展示。
· 文献管理列表支持勾选多选：「全选」作用于当前筛选结果（搜索 / 标签 / 期刊 / 日期筛选后再全选可精准圈定范围）， 「删除所选」批量删除并经页内确认列出标题清单；勾选状态跨筛选与翻看保留，单条「删除」按钮照常可用。
· 每周速递：上传周报 md 自动两件事 —— ① 落盘 content/weekly/，周报页随构建收录； ② 解析「# 文献N」小节，DOI 抓取元数据入库生成主页卡片（周报自带中文标题 / 摘要 / 体裁注记直接预填， 不走大模型；缺中文可事后用「翻译缺中文的」回补）。文献封面优先用本期图表图，图表为无或下载失败用站点 logo 兜底。
· 周报同名文件重复上传 = 覆盖更新该期（库内已有 DOI 自动跳过）；「删除此期」只删周报页， 已生成的文献卡片需到文献管理单独删除；期次列表同样支持勾选多选， 「删除所选」批量删并经页内确认列出期次清单。
· 发布 = 写 meta/papers.json → build_site.py → git add/commit/push →（可选）同步服务器。
