# MacroBiodiv 部署操作手册

> 按顺序做完即可上线 `https://macrobiodiv.zbhgis.com`。
> 【你来做】的步骤需要登录阿里云控制台或服务器；【已完成】的部分不用动。

## 步骤 ③：DNS 子域解析【你来做】

阿里云控制台 → 云解析 DNS → zbhgis.com → 添加记录：

```
记录类型：A
主机记录：macrobiodiv
记录值：  47.98.133.104     （与主站同一台 ECS）
TTL：     10 分钟
```

验证（本地 CMD/PowerShell）：`nslookup macrobiodiv.zbhgis.com` → 应返回 47.98.133.104。

## 步骤 ④：服务器上签证书 + 配 Nginx【你来做】

SSH 登录服务器（你平时的方式）后依次执行：

### 4.1 建 acme 验证目录
```bash
mkdir -p /var/www/acme/macrobiodiv
```

### 4.2 给子域签发证书（复用主站的 acme.sh 与 webroot）
```bash
acme.sh --issue -d macrobiodiv.zbhgis.com \
  --webroot /opt/mystation/frontend \
  --keylength ec-256
```
> 说明：验证请求打到 80 端口时由主站的 nginx 块兜底服务（webroot 在主站目录里），
> 与 geosciplot 子域的签发方式一致。

### 4.3 安装证书（续期时自动 reload）
```bash
acme.sh --install-cert -d macrobiodiv.zbhgis.com --ecc \
  --cert-file      /etc/nginx/ssl/macrobiodiv.zbhgis.com.cer \
  --key-file      /etc/nginx/ssl/macrobiodiv.zbhgis.com.key \
  --fullchain-file /etc/nginx/ssl/macrobiodiv.zbhgis.com.fullchain.cer \
  --reloadcmd      "nginx -s reload"
```

### 4.4 部署 Nginx 配置
配置文件已在仓库里：`deploy/nginx-macrobiodiv.conf`（证书路径已对齐 4.3）。
上传到服务器后：

```bash
# 本地 Git Bash 里执行
scp deploy/nginx-macrobiodiv.conf root@47.98.133.104:/etc/nginx/conf.d/macrobiodiv.conf

# 服务器上
nginx -t && nginx -s reload
```

### 4.5 建站点目录并放行本机公钥（供管理界面一键同步）
```bash
mkdir -p /var/www/macrobiodiv
# 若尚未把本机公钥加进 authorized_keys（geosciplot 配过则跳过）：
echo "ssh-ed25519 AAAA...你的公钥" >> ~/.ssh/authorized_keys
```

## 步骤 ⑤：站点文件上服务器

管理界面点「发布」（勾选"同步到服务器"）即可自动完成。手动方式：

```bash
cd site && scp -r ./* root@47.98.133.104:/var/www/macrobiodiv/
```
